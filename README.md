# SevenMentor – IT Training Institute Website

A front-end training institute website created as a class project using HTML and CSS.

## Features

- SevenMentor-style training institute homepage
- Top navigation and social media icons
- Hero section with job-ready training messaging
- Animated experience, student, hiring partner and course counters
- Alumni / company logos section
- Why SevenMentor section
- Free demo call-to-action
- Industry-focused platform section
- Course search and course categories
- Course cards with duration, fees, placement and ratings
- Industry affiliations and NASSCOM certification section
- Professional certification cards
- Collaboration section
- Responsive styling for different screen sizes
- Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Media Queries
- Font Awesome

## How to Run

Open `index.html` in a browser.

For development, use VS Code with Live Server.

This is a static front-end project and can be deployed from the `main` branch using GitHub Pages.
